# guokao 方法论与口径细节

## 方法论主线

**硬性条件布尔过滤 → 个性化意向加权打分排序 → 带理由交付**。

- 当年表（如 2027）是唯一报名决策依据；历史三年（2024-2026）只产出「部门连续招录画像」，**不参与主排序**。
- 全部过滤与打分由 `scripts/guokao_run.py` 确定性完成，模型不逐行判断岗位。

## 硬过滤规则（引擎实现，模型需理解以便解释）

| 条件 | 规则 | 数据来源 |
|---|---|---|
| 性别 | 备注含"限男性/限女性"→ 硬过滤；"适合男性/女性"→ 人工确认提示 | 备注列正则 |
| 年龄 | 备注有单独限定（如 30 周岁以下）→ 用之；否则公告默认 35（应届硕士/博士 40）。报名口径 = 上年 10 月。年龄离默认上限 <0.5 岁时 stats 输出 profile_warnings | 备注解析 + 公告口径 |
| 学历 | 阶梯匹配：仅限大专/大专或本科/仅限本科/本科及以上/本科或硕士/仅限硕士/硕士及以上/仅限博士。解析失败 → 需人工确认 | 学历列 |
| 学位 | 要求学士/硕士/博士 → 用户学位等级须达标；"与最高学历相对应"→ 放行 | 学位列 |
| 政治面貌 | 中共党员 → 用户须党员（含预备）；党员或共青团员 → 党员/团员 | 政治面貌列 |
| 基层年限 | 用户年限 ≥ 要求（无限制=0，五年以上=5） | 基层工作最低年限列 |
| 服务基层项目 | 该列非"无限制" → 用户须 base_project_eligible=true | 服务基层项目工作经历列 |
| 应届限定 | 备注含"仅限应届/XXXX年应届" → 用户须应届 | 备注解析 |
| 四六级 | 备注含四级/六级要求 → cet4/cet6 ≥ 425 | 备注解析 |
| 专业 | 见下"专业匹配" | 专业列 + 双目录 |
| 户籍/生源 | 无法自动判定 → 一律进「需人工确认」 | 备注解析 |

## 专业匹配（宽匹配三通道 + 税务硬门）

1. 用户专业经**教育部本科目录**映射出：专业名、代码、专业类（如计算机类）、门类。
2. 岗位「专业」单元格拆词元（剥"本科为/研究生为"前缀、学科代码、括注）后与上述集合比对，命中通道：代码 > 专业名 > 专业类 > 门类（门类命中标记为宽匹配）。
3. **税务岗只认税务系统目录**（`clean/catalog/tax_major.csv`）：用户专业须出现在某税务类别下，且该类别名或专业名出现在岗位要求里；专业完全不在税务目录 → 排除（reason=tax_catalog）。
4. 专业单元格为"不限" → 直接通过。
5. 模型须在交付时说明：专业为宽匹配，边缘专业以招录机关解释为准。

## 待遇粗评估（预置分类评分，用户已拍板方案）

```
treatment_score = 0.6 × 地区档(ref/region_treatment.csv) + 0.4 × 系统档(ref/system_treatment.csv)
```

- 地区档：省基础档 + 计划单列市/强市覆盖行（如广东深圳=9、江苏苏州=9），匹配键 = 省+市（无则省）。
- 系统档：关键词扫描 部门名称+用人司局+职位属性（长关键词优先，如"公安机关人民警察职位"），未命中按机构类别兜底（党群8/部委8.5/参公6/省以下直属6）。
- 两张表在数据仓库 `ref/` 下，**改档位只改表不改代码**；报告必须标注"粗评估，非实际收入"。

## 打分模型

```
总分 = Σ(权重_i × 单项分_i) / Σ权重_i    （0-10 分）
单项分：near_home 同城10/同省7/其他2；treatment 直接用粗评分；
        unit/system/region 关键词命中10未命中0（region 未命中3）；
        level 层级命中10。
```

并列时按招考人数降序。不可计算意向（晋升空间、工作强度等）不参与，模型须主动告知用户。

## 数据链与更新

- 职位表：每年 10 月中旬官方发布 → 更新 raw → clean → manifest（步骤见 SKILL.md）。
- 进面分数（`{year}_report.csv`，规划中）：每年 1-3 月面试名单，口径「最低进面分数」，缺口年份标缺失，禁止用空数据硬算难度。报名期（10 月下旬）官方每日报名人数统计可作为更早的难度代理指标（v2）。
- 历史画像：目标部门近三年 招X人/Y岗 连续性，仅附录展示。

## 合规

公开招录信息的个人整理，raw 件随附 source.txt（来源+日期）可追溯。整理数据对外售卖/增值服务化需谨慎（灰色地带）。
