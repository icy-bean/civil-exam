# /civil-exam 真实对话演练手册（第一个用户实测用）

目的：在 2027 新表落地前，用 2026 真实数据把 skill 的**对话路径**完整走一遍——触发、交互、引擎调用、结果解读、异常处理。全程约 15 分钟。

## 0. 准备（1 分钟）

- **新开一个全新的会话**做测试（Claude Code / Codex / ZCode 等支持 skills 的工具均可），不要在开发会话里继续——避免上下文"剧透"影响触发测试。
- 新建一个空目录作为工作目录（如 `D:\civil-exam_test\`），运行产物会落在这里。
- 数据源就绪：本地克隆了本仓库就把 `data_source.json` 的 local_path 指向克隆目录；留空则走远端自动同步（见场景 E）。

## 1. 场景 A：触发 + 画像收集

在新会话里输入一句自然的话：

> 帮我看看 2026 国考有什么岗位适合我

**预期**：
- 自动触发 civil-exam skill（不是泛泛聊公务员）；
- 画像收集给一个**可整段复制的填写模板**（已知项预填、未知项留空），你填好发回即可——如果它让你"能填多少填多少"地自由描述，记为问题；
- 你说不出意向权重时，主动给"求稳/离家近优先/待遇优先"预设画像。

## 2. 场景 B：完整跑通（建议画像，故意埋了 4 个测试点）

用这组画像回答：

- 女 / 2002-03 生 / **中共预备党员** / **硕士研究生、应届** / 专业：**计算机技术** / 六级 480
- 家在浙江杭州；意向：离家近 9、待遇 8、系统偏好 [税务、海关]、地域 include [浙江、上海]、exclude [西藏]、层级 市（地）级

测试点与预期：
1. 预备党员 → 应按"党员"口径通过政治面貌过滤；
2. 应届硕士 → 年龄上限按 40 而不是 35；
3. "计算机技术"（专硕名）→ 应能解析进目录类别，不能解析时明确说"需人工确认"而不是硬排除；
4. exclude [西藏] → 西藏岗位硬排除并计入落选统计。

回显确认后放行 → 预期：跑引擎，交付 xlsx + md 报告。

## 3. 验收清单（对照打勾）

- [ ] 画像落盘为工作目录的 USER.md（并说下次可复用）
- [ ] 模型复述了漏斗数字：总岗位 → 可报 → 需人工确认（2026 应约为 20,714 → 2,3xx → 数百）
- [ ] Top 10 每条理由引用**具体匹配事实**（工作地点/系统命中/待遇档位），而不是"很适合你"
- [ ] 需人工确认清单被明确列出，特别是「备注含限定表述但规则未识别」的条数与样例
- [ ] 报告声明了三件事：不含进面分/报录比；待遇分是粗评估非实际收入；专业为宽匹配以招录机关解释为准
- [ ] 聊天里的 Top 岗位**带职位代码**，xlsx 有「职位代码 + 原表工作表」列，能回查官方原表
- [ ] 产物落盘：`civil_exam_2026_结果.xlsx`（4 个 sheet）+ `civil_exam_2026_报告.md`

## 4. 场景 C：异常路径（最重要的负向测试）

输入：

> 那直接用 2027 年的表帮我选岗

**预期**：明确告知"2027 表官方约 10 月中旬发布、数据仓库尚未收录，请先更新数据源"，**绝不拿 2026 表冒充 2027 分析**。

## 5. 场景 D：修改画像重跑

> 其实我也想去深圳，离家近权重降到 5

**预期**：更新 profile 直接重跑，不再从头盘问；新一轮报告的离家近得分与排名发生合理变化。

## 6. 场景 E：冷启动（模拟"用户只装了 skill，没有本地数据仓库"）

1. 编辑 skill 的 `data_source.json`，把 `local_path` 的值改成 `""`（**先记下原值，测完恢复**）；
2. 删除或改名缓存目录 `C:\Users\<你>\.civil-exam\data`（若存在），确保全新下载；
3. 重跑场景 A/B；
4. **预期**：引擎提示「开始从远端同步 N 个数据件（约50MB，首次需数分钟）」→ 数分钟内完成 → 出报告，结果与本地模式一致（每一件都过了 SHA256 校验）；
5. 测完把 `local_path` 改回原值。需要 GitHub raw 可达（本机代理开着即可）。

## 7. 反馈

把所有别扭的地方记下来反馈给开发者修 SKILL.md：追问轮数多、话术生硬、数字没解释、产物难读、触发不灵、报告遗漏提醒……越具体越好。
